SuperMart — Sales Dashboard (Excel Portfolio Project)
Overview

SuperMart is an Excel-based sales analytics dashboard built to analyze retail transaction data across multiple regions and product categories. It demonstrates data cleaning, pivot table analysis, and dashboard design skills using Excel.

Dataset
500 transactions
5 regions
5 product categories

Tools Used
Microsoft Excel (Pivot Tables, Charts, Formulas)

About This Project

Built as part of a data analytics portfolio to demonstrate Excel proficiency in sales data analysis and dashboard design.
